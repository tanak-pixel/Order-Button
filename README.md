# 🛍️ Order Button Component

A clean, responsive, and reusable **"Order" button component** designed for e-commerce applications and checkouts. It provides clear user feedback by cycling through various states (default, loading, success) during a transaction.

---

## ✨ Features

* **State Management:** Built-in states for normal, loading, and successful order submission.
* **Customizable:** Easily change colors, text, and icons to match your application's design.
* **Accessibility:** Optimized for keyboard navigation and screen readers.
* **Lightweight:** Minimal dependencies for fast performance.

## 🚀 Installation

If you're using this as a simple front-end component (HTML/CSS/JS):

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/tanak-pixel/Order-Button.git](https://github.com/tanak-pixel/Order-Button.git)
    ```
2.  Include the necessary **CSS** and **JavaScript** files in your project.

*(**Note:** If your component is packaged for npm/yarn, replace the steps above with the appropriate package installation command.)*
